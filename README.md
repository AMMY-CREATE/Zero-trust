# Ammy Project

Welcome to the Ammy Project. This is a Zero Trust application.

## Getting Started

### Prerequisites

- Node.js & npm installed

### Installation

```sh
# Install dependencies
npm install
```

### Development

```sh
# Start the development server
npm run dev
```

### Build

```sh
# Build for production
npm run build
```

## Technologies Used

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
